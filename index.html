シフト作成の手順
  1. シフト案を作る 各人の基本公休曜日を公休にし、提出された希望（休み・代わりの出勤）で上書きして、下の表にシフト案を作ります。希望が出ていない人は基本公休曜日だけで組みます。
  2. 案を確認・修正する 「確定前確認事項」と下の表を見て、直したいマスをタップします。
  3. シフトを確定する 確定すると次の2つを行います：
    ・ハーモス取込用のCSVファイルを作成
    ・休み／有休／パート出勤日をGoogleカレンダーに登録     確定前の状態に戻します。Googleカレンダーに登録した予定を削除し、シフトを「案（未確定）」に戻します。
    ※すでにハーモスにCSVを取り込んでいる場合、ハーモス側の内容は元に戻りません。
  4. ハーモスに取り込む 押すとCSVファイルがダウンロードされ、Claudeへの依頼文がコピーされます。依頼文を Claude Code に貼り付けると、ClaudeがChromeでハーモスに取り込み、⑤の確認まで行います。
    ※ハーモスはシステムから直接シフトを登録できないため、CSVで取り込みます（手作業で取り込んでもかまいません）。
  5. 取り込み結果を確認する 確定シフトとハーモス上のシフトを1日ずつ照らし合わせ、食い違う日を一覧表示します。
勤務の実績を確認する（月の途中・月末） シフトの予定と、ハーモスの実際の打刻を昨日分まで照らし合わせ、「出勤予定なのに打刻なし」「休み予定なのに打刻あり」の日を一覧表示します。シフトは自動では直しません。
